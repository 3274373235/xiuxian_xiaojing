# xiuxian_xiaojing

**✨ 基于xiuxian2.2魔改版的优化版本 | 🤖 作者：小靖 (sonder)**

---

## 🎯 项目简介
本仓库为QQ修仙机器人小靖官机源码，基于经典的xiuxian2.2魔改版进行二次开发优化。延续了xiuxian1.0/2.0的核心玩法，并新增功能与系统优化，此代码可实现部署即使用（官机）

---

## 🚀 功能特性
✅ **继承经典玩法**  
- 兼容xiuxian2.0/2.2指令体系

🆕 **新增优化内容**  
- 已完善缺失代码
- 更改了原本的境界体系
- 新增多项指令
- 修改了坊市为全服坊市而非群组坊市
- 增加了如永恒轮回等新功能
- 懒得写了自己探索……

### 环境要求
- Python 3.8+
- Gensokyo

### 快速部署
```bash
# 部署方法请参考xiuxian2.0和xiuxian2.2魔改版
主要注意xiuxian2.0页面的配置文件板块，当前项目中缺失的文件需要在那里下载
# 安装依赖
pip install -r requirements.txt
```
